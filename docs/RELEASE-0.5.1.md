# Full-character coverage requirements

Full character batches now automatically require walk, run, attack, death and jump. Additional actions are preserved and cannot replace these five. Explicit action studies remain available with a reason and are labeled separately. Old incomplete scopes require a revised batch, preserving their prior work as history.

Final extraction also rejects changes to the reviewed grid, frame count or phases before touching existing output. Full sprite sheets remain the default generation unit; inspecting each frame does not require generating individual images.

Validation: 48 automated tests pass. These check workflow and export behavior, not artistic quality. Current game samples have not passed whole-sequence artistic acceptance, and no game artwork is included in this distribution.
