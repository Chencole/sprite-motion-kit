# 0.5.2

Preserve approved external 3D animation references through preparation,
generation requests, pose review and export. Whole-sheet requests now carry
explicit per-cell origins and ground coordinates on this path.

Fix the pose gate accepting a correctly angled but vertically shifted row.
Reject opaque cell perimeters masquerading as alpha. Imported jobs declare
solid-magenta extraction or genuine-alpha output, preserve airborne/root motion,
and support a settled endpoint for non-looping animations. Full characters still
require walk, run, attack, death and jump, with additional actions allowed.

The plugin enforces measurable contracts; it does not guarantee that an image
generator produces perfect art. Generated single-character demos remain subject
to visual acceptance before game replacement.
